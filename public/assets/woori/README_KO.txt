우리유형 테스트 메인 화면 에셋
- main_image_reference.png: 원본 디자인 레퍼런스(배경+스톤 합성)
- background_complete_no_stone.png: 스톤 없는 독립 배경(원본을 기반으로 재구성한 이미지)
- background_blur_grid.png: 아이보리 배경, 블러, 가이드라인
- background_shapes.png: 오렌지/차콜 타원 오브젝트(투명 배경)
- transparent_glass_stone.svg / .png: 중앙에 사용할 독립 무색 투명 유리 스톤(알파 투명)
- type-*.svg: 기존 4종 컬러 스톤 이미지(참고용; 각인과 컬러 스톤이 합쳐져 있음)

주의: 스톤 없는 배경과 독립 유리 스톤은 원본 main_image에서 픽셀 단위로 정확히 분리한 결과가 아니라 시각적 구성을 재구성한 에셋입니다.
유리 스톤 SVG는 실제 벡터 요소이며 중앙이 투명합니다. 기존 type-*.svg는 PNG를 내장한 SVG입니다.
각인만 분리된 4종 독립 에셋은 이 패키지에 포함되지 않습니다.
